# 쓰지 않게 된 것 (2026-11-15)

자료(장부·명단)를 비공개 저장소 `paper-exchange-data` 로 옮기면서 쓰지 않게 된 것들이다. 지우지 않고 옮겨 두었다.

- `issue-window.yml` — 공개 저장소의 이슈로 주문·관리 명령을 받던 자동 실행. 이슈는 누구나 보므로 포트폴리오·참가자 이메일이 새어 나간다.
  주문은 sharktalk 주문 페이지(→ 자료 저장소 `inbox/{이름표}/`), 관리 명령은 관리자 화면(→ 자료 저장소 `admin/`)으로 받는다. `broker.py issue` 명령은 남아 있다.
- `ISSUE_TEMPLATE/` — 위 이슈 양식.
- `commit.sh` — 자료를 이 저장소에 올리던 스크립트. 이제 `.github/commit-data.sh` 가 자료 저장소에 올린다.
